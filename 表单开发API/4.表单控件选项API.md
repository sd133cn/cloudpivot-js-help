# 4. 表单控件选项API

在表单控件API文档中我们得知不同类型控件的选项是不同的，控件选项是在表单设计器设计时生成的。在运行时只有极少数的属性修改会产生影响，尽管如此也不建议在运行时修改选项属性，了解属性详细含义有助于我们排查错误。
