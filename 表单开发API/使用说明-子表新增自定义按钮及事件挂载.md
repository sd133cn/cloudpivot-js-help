# 一、子表新增自定义按钮

## （一）自定义按钮元素结构

| 标签名 | a-sheet-action | |
| --- | --- | --- |
| 标签属性 | code | 按钮编码，必填 |
| | text | 按钮名称，必填 |

# 二、子表扩展“自定义按钮”点击事件

## （一）子表自定义按钮事件挂载

* 子表控制器中提供钩子`sheetActionDown`用于挂载子表自定义按钮点击事件
* 通过钩子`sheetActionDown`挂载的方法为通用方法，即目标子表的任意一个自定义按钮点击均会执行该方法
* 可通过钩子`sheetActionDown`同时挂载多个子表自定义按钮点击事件，当自定义按钮点击时，将顺序执行当前子表挂载的所有自定义按钮点击事件
* 自定义按钮点击事件入参为一个`object`，内部结构为：
  * `code`：按钮编码
  * `checkeds`：当前勾选子表行数据
  * `value`：当前子表全部数据

## （二）使用示例

### 1、配置

```javascript
(function(form){
  /**
   * 用户自定义JS区域
   */
  /**
   * 事件绑定，form.on
   * @param eventType 事件类型
   * @params function 事件
   * @param  cover    true, false 是否覆盖root的生命周期 默认不覆盖 
   */
  //数据加载后，渲染之前，this为window
  form.on('onLoad',function(data, dataPermission){},'cover');
  //渲染完成后
  form.on('onRendered',function(data){
    this.Sheet1671528710462.sheetActionDown((...args) => {
      console.log('这是第一个点击事件', ...args);
      const event = args[0];
      switch(event.code) {
        case 'customActionCode1':
          console.log('自定义按钮1执行第一个点击事件');
          console.log('当前子表数据：', event.value);
          console.log('当前子表勾选数据：', event.checkeds);
          break;
        case 'customActionCode2':
          console.log('自定义按钮2执行第一个点击事件');
          console.log('当前子表数据：', event.value);
          console.log('当前子表勾选数据：', event.checkeds);
          break;
        default:
          break;
      }
    })
    this.Sheet1671528710462.sheetActionDown((...args) => {
      console.log('这是第二个点击事件', ...args);
      const event = args[0];
      switch(event.code) {
        case 'customActionCode1':
          console.log('自定义按钮1执行第二个点击事件');
          console.log('当前子表数据：', event.value);
          console.log('当前子表勾选数据：', event.checkeds);
          break;
        case 'customActionCode2':
          console.log('自定义按钮2执行第二个点击事件');
          console.log('当前子表数据：', event.value);
          console.log('当前子表勾选数据：', event.checkeds);
          break;
        default:
          break;
      }
    })
  });
  //内置校验完成后，返回false阻止提交(
  form.on('onValidate',function(action,data){});
  //操作前（包含自定义按钮）执行，返回false阻止按钮操作)
  form.on('onPreAction',function(action,data){});
  //自定义按钮执行'
  form.on('onCustomAction',function(action,data){});
  //操作完成后执行"
  form.on('onActionDone',function(action,data,httpRes){});
})
```
