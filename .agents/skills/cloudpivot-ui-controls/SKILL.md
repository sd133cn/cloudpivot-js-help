本 skill 装**控件**，不装业务：每个控件只定义骨架、变体与状态类；业务取值（选项叫什么、状态有几档）是调用方填的**槽位**，文档里一律写成 `<…>`，不出现具体取值。

本 skill 自洽——骨架与式样都在 `references/` 里可直接粘贴，不依赖任何具体表单的文件。**边界**：跟平台对话的事（生命周期事件、子表 `rowStatus`、OpenWebAPI）归 `cloudpivot-form-dev`，本 skill 只管外观与组合。

## 命名与落地

- 件库命名空间 `pv-`。文档里的选择器一律写成 `<件根> .pv-xxx`：`<件根>` 换成该表单件根的 `id` 选择器，`pv-` 可整体换成该表单自己的前缀（同名替换，不改结构、不改状态类名）。

## 变体与状态分开

- **变体**在 HTML 里选定，写完不再变：一个控件是「实心主按钮」还是「描边按钮」、选项组是 chips 还是 Segmented——用类表达（`pv-btn-primary`、`pv-seg`）。
- **状态**由 JS 翻 `is-*` 类，绝不写内联 `style`；CSS 只认状态类与 `data-*`，绝不认 JS 塞的样式。
- 混用就坏了：把选中态写成变体类，切换得改 HTML；把变体写成 `is-*`，JS 会顺手关掉主按钮。

## 组合模型

- **一个界面一个件根**：token 与 `.is-hidden` 只挂件根，控件全在其下继承，不各自复制 token。Bottom Sheet 打开时临时挂到 body，浮层宿主成为第二个 token 宿主，见 `controls.md` §2。CSS 选择器全部限定在件根或浮层宿主，且只命中自定义元素（不碰 `a-*` 控件）。
- **枚举只落一处**：业务取值只出现在①数据的 `data-*` 和②件根下的状态映射表。式样规则里不写死取值，加一档状态只改映射表一行。
- **控件互不认识**：跨控件只通过字段容器（label + 控件位 + 错误位）和显隐组合，不引用彼此的 id。id 只用来定位「谁是主操作」「哪个字段要显隐/报错」。
- **一屏一个实心主按钮**：跨控件约束——按钮栏与浮层动作栏各自最多一个实心档，且同屏只出现一个；浮层打开时把页面主按钮 `disabled`。
- **z-index 只有一档**（浮层 1000）；控件内部不许再加。

## 执行顺序

1. **选控件与变体**，别重造：按目录表挑件，从 `controls.md` 对应节整段摘骨架与式样，不拆结构、不换标签。
   **完成判据**：每个用到的控件都能指出 `controls.md` 的节号；目录里没有的才自造，且必须照同一写法（件根下、变体类 + `is-*` 状态类、取值走 `data-*`）。
2. **定槽位**：选项/状态取值集与顺序、文案、id 前缀、谁是主操作、每档状态选哪个预设色档。
   **完成判据**：能列出映射表要几行、每行 `-1 / -7` 是哪两档；主操作是谁。
3. **三处落笔**：HTML 骨架 / CSS token + 式样 / JS 只翻状态类。
   **完成判据**：表单 JS 里没有 `style.` 赋值（唯一例外：浮层打开时压平台底部操作条，见 `controls.md` §2）。
4. **探针验**：本地预览 harness 按控件 × 状态取 `getComputedStyle`。
   **完成判据**：目录表里本次涉及的**每个控件、每个变体、每个状态类**，加映射表的**每一档取值**，都有一条实测值 == 期望值；再核互斥取值之间的色差。缺一条回第 3 步，**不许**以「截图看着对」交付。
5. **同批复贴**：三件套一起进平台三扇编辑窗。
   **完成判据**：说清本批改了哪几扇窗。

## 死路（实测，别再试）

- **三件套漏贴一扇窗**：式样与骨架是一对。状态属性的宿主元素挪过（比如从内层色点挪到整个徽标），只贴 CSS 不贴 HTML 就整组没色。改过 HTML 就把三件一起复贴。
- **`<a-col>` 第一个子元素用 `class`**：云枢渲染时会剥掉它，件根节点一律用 `id`。
- **HTML 窗口写 `<link>` 外部样式表**：不生效。外链只有 `<script src>` 一条路。
- **Bottom Sheet 在原容器抬 `z-index`**：旧 iOS WebKit 会被 `.form-body` 滚动容器裁掉整栏动作按钮；打开时挂 body、关闭还原，CSS 同时认件根与浮层宿主，见 `controls.md` §2。
- **照搬 v6 桌面尺寸**：v6 `control-height` 32px 是桌面值，移动端 webview 点不准。配色/圆角/层级/动效照 v6，**高度**按 44px 下限（chip 36px）。
- **靠截图比色**：浅状态色之间差 2% 肉眼分不出，探针能量出来。
- **把业务取值写进式样规则**：一旦写死，换单据就得重写 CSS；取值只走 `data-*` + 映射表。
- **给按钮加 `opacity` 表 disabled**：浅底上会糊掉文字；改底色 `--pv-bg-layout` + 文字 `--pv-text-dis`。
