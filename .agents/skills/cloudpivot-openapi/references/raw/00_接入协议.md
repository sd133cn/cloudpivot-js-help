# 文档概述


## 编写目的


本文档是为第三方平台开发者接入奥哲云枢开放平台编写的,它阐述了开发者接入奥哲云枢开放平台的规范及协议,同时提供了使用示例。



## 适用范围


需要接入奥哲云枢开放平台的第三方平台开发者。



# 奥哲云枢开放平台接入说明


## 第三方平台接入流程


+  1.申请接入，获取第三方平台的client_id、client_secret。 
+  2.通过OAuth2的客户端模式，获取访问资源服务的token。 
+  3.使用token，配置参数，与奥哲云枢开放平台OpenAPI接口交互。 



## 接入协议


奥哲云枢开放平台采用国际通用的OAuth2标准协议，稳定安全，其鉴权模式为标准的Oauth2的client鉴权模式。

# OpenAPI接口
### 接口传参及定义
参数个数及形式不做限制，根据具体的method(post/get)定义传参类型，命名格式如下

```java
public ResponseResult<XXXYYResponse> XXX(@RequestBody XXXYYRequest req)
```

### 接口入参中组织相关字段优化
支持使用corpId+sourceId（业务主键）来替换相关组织元数据的id字段，业务主键的值格式为json格式对象类型，具体字段说明可查看每个接口相关接口说明。

<font style="color:#DF2A3F;">（其中 sourceId字段对应h_org_department,h_org_role,h_org_role_group中sourceId字段值，对应h_org_user表中userId字段值）</font>

示例：

```java
原数据结构
{
    ...,
    "departmentId":"12314213",
    "userId":"222222222",
    ...
}

新数据结构
{
    ...,
    "deptBizId":{
        "corpId":"abc",
        "sourceId":"source"
    },
    "userId":{
        "corpId":"abc",
        "sourceId":"source"
    },
    ...
}
```



### 接口路径
按照engine API相同的领域划分open API的url路径，格式为

```java
http://${host}/${context}/openapi/v3/${domain}/${method}
```

如：http://example.com/api/openapi/v3/bo/get"。

v1、v2版本的openApi将全部标识为废弃(swagger文档中以删除线显式显示)

### 接口返回值
http status均为200，即均为http请求成功，接口定义的返回值类型为ResponseResult<T>，

    public static String accessToken(){
        String accessToken = null;
        OAuthClient oAuthClient = new OAuthClient(new URLConnectionClient());

        OAuthClientRequest accessTokenRequest = null;
        OAuthAccessTokenResponse oAuthResponse = null;
        try {
            accessTokenRequest = OAuthClientRequest
                    .tokenLocation(ACCESS_TOKEN_URL)
                    .setGrantType(GrantType.CLIENT_CREDENTIALS)
                    .setClientId(CLIENT_ID)
                    .setClientSecret(CLIENT_SECRET)
                    .setScope(SCOPE)
                    .buildQueryMessage();

            //去服务端请求access token，并返回响应
            oAuthResponse = oAuthClient.accessToken(accessTokenRequest, OAuth.HttpMethod.POST);
        } catch (OAuthSystemException e) {
            e.printStackTrace();
        } catch (OAuthProblemException e){
            e.printStackTrace();
        }
        if(oAuthResponse!=null){
            //获取服务端返回过来的access token
            accessToken = oAuthResponse.getAccessToken();
            String tokenType = oAuthResponse.getTokenType();
            System.out.println("-----------客户端/tokenType---------------");
            System.out.println(tokenType);
        }
        return accessToken;
    }
